
# iPhone Calculator

A modern iPhone-style calculator built with **HTML, CSS, and Vanilla JavaScript**.  
This project replicates the iOS calculator UI and includes advanced features like history tracking, keyboard support, and expression handling.

---

## ✨ Features

- Basic arithmetic operations: `+`, `−`, `×`, `÷`
- Percentage calculation
- Delete (⌫) last input
- Clear (AC) reset
- Live expression display
- Calculation history (click to reuse results)
- Keyboard support (desktop-friendly)
- Responsive iPhone-style UI
- Error handling for division by zero

---

## 🧠 Project Logic

The calculator is fully built using **DOM manipulation in JavaScript**:

- UI elements are created dynamically
- State is managed using variables:
  - `currentValue`
  - `previousValue`
  - `operator`
  - `expression`
- A history array stores last calculations
- Each button triggers a specific action handler

## 🚀 How to Run

1. Clone the repository:
```bash
git clone https://github.com/MB-FALAH/iPhone-Calculator.git
````

2. Open the project folder:

```bash
cd iPhone-Calculator
```

3. Open `calculator.html` in your browser.

No installation or dependencies required.

## ⌨️ Keyboard Shortcuts

| Key         | Action        |
| ----------- | ------------- |
| 0–9         | Input numbers |
